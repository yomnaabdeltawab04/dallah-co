# Dallah & Co. ☕

A multi-page café website for a fictional Dubai-based coffee shop that blends Arabic coffee traditions with modern café culture.

## Live Demo
[View Live Site](https://yomnaabdeltawab04.github.io/dallah-co)

## Tech Stack

- **HTML5** — semantic page structure across 4 pages
- **CSS3** — custom styling, responsive design, grid & flexbox layouts
- **No frameworks** — built entirely from scratch

## Pages

- **Home** (`index.html`) — hero section, menu highlights, visit info
- **About** (`about.html`) — brand story, mission, and café experience
- **Menu** (`menu.html`) — full menu with categories and AED pricing
- **Contact** (`contact.html`) — contact form and location info

## How to Run Locally

1. Clone the repo:
   ```bash
   git clone https://github.com/yomnaabdeltawab04/dallah-co.git
   ```
2. Open `index.html` in your browser — no installs needed.

## Retrospective

If I were to rebuild this project, I would add a **mobile hamburger menu** instead of a stacked nav on small screens — the current mobile nav takes up too much vertical space. I'd also use **CSS custom properties (variables)** for the color palette from the start rather than repeating hex values throughout the stylesheet, which would make theming much easier to maintain. Finally, I'd connect the contact form to a real backend service like Formspree so it actually submits messages.
